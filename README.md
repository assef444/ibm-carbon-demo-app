# IBM Carbon Design System Dashboard

A demo React web app built with **Vite**, **TypeScript**, and **Sass**, strictly following the **IBM Carbon Design System**.  

The goal of this project is to explore **clean (frontend) software engineering principles**, **modular architecture**, and **frontend best practices** in order to gain a solid background in React for **future system architecture and design decisions**.

---

## Live Demo
Check out the public demo here: [demos.cassia.solutions/dashboard-app](https://demos.cassia.solutions/dashboard-app).

---

## Highlights
- Structured and scalable project architecture  
- Fully aligned with the IBM Carbon Design System  
- Built with modern frontend tools (Vite, TypeScript, Sass)
