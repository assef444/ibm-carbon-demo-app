# IBM Carbon Design System Dashboard

## Contexto
Quiero crear una React web app siguiendo al pie de la letra el IBM Carbon Design System.

## Objetivo del Proyecto
Entender profundamente el frontend development de React con sus prácticas y buena ingeniería de software, a través de la puesta en práctica de la teoría del IBM Carbon, para poder crear web apps de cualquier use-case y poder mejorar la toma de decisiones sobre el diseño de la arquitectura de un sistema. Básicamente quiero poder tener un background en React para tener experiencia a la hora diseñar la arquitectura de una solución y saber qué se puede y qué no.

## Stack Tecnológico
- React
- TypeScript
- Sass
- Vite

## Constraints
- Me especializo en el backend development + infraestructure + arquitectura, el frontend NO es mi fuerte, entonces, a la hora de mencionar un concepto, también explicarlo como si fuera dummy.
- Este proyecto es DEMO, no será el use-case real productivo, es solo de aprendizaje.
- El order y la estructura es lo MÁs importante de una solución, por lo que todo tiene que lo más estructurado, desacoplado, modular y estandarizado posible.
